# Micrograd

A minimal implementation of automatic differentiation and neural networks built from scratch in Python, inspired by Andrej Karpathy's Micrograd.

## What I Implemented

- Computational graphs
- Automatic differentiation
- Backpropagation
- Gradient descent
- Neurons and layers
- Multi-layer perceptron (MLP)

## Project Structure

- `micrograd_demo.ipynb` — implementation and experiments

## Concepts Learned

This project helped me understand how neural networks work internally, especially how gradients are computed using backpropagation and how they are used to update model parameters.

## Reference

Inspired by Andrej Karpathy's [micrograd](https://github.com/karpathy/micrograd).
